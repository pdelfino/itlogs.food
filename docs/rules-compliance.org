* Coding assistant
Built with Claude Code (Anthropic) as a coding assistant, disclosed in a =Co-Authored-By= trailer on the commits. The Official Rules allow a third party for technical assistance when the components remain the participant's own work and the participant owns all rights to them. Meta's toolkit documentation has its own Claude Code setup page, https://wearables.developer.meta.com/docs/develop/dat/ai-assisted-claude-code, and this project used Meta's =mwdat-ios= plugin from it. The Meta models are what the product runs on.

* Platform policies
Meta's Wearables Developer Terms and Acceptable Use Policy (https://wearables.developer.meta.com/terms, https://wearables.developer.meta.com/acceptable-use-policy):
- Use: "hands-free capture and logging" is among the uses Meta's guidance encourages (https://wearables.developer.meta.com/docs/develop/dat/acceptable-use). The app runs in Developer Mode on the entrant's own glasses and is not distributed.
- Recording: the camera runs only between Start and Stop, which the wearer taps, and the code does not touch the glasses' capture light. Nothing identifies people. The stream is not written to disk.
- Retention: recording is off unless =ITLOGS_RECORD_DIR= is set, and then only the frames that were read are kept, in a local folder, never in git.
- Privacy policy: https://itlogs.food/privacy.html
- Health: the app writes food samples to Apple Health when the wearer confirms a meal, and reads back only the energy it wrote. Not a medical device, and it holds no protected health information.
- Model API: standard-mode model ids only, which do not train on the content.
